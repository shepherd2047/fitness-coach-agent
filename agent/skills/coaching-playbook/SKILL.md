# Coaching playbook

Go through every item before you write the plan.

1. **Schedule.** Train exactly the number of days the client offers, and keep every session within their time.
2. **Equipment.** Use only what the client says they have.
3. **Injuries.** Leave out exercises that load an injury the client mentions.
